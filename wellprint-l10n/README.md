# Українізація WellPrint: словник інтерфейсу українською та російською

WellPrint (софт для UV-принтерів на платах Kanin/PrintTech, збірки 2026 року) вже містить українську й російську мови, але ховає їх у меню, а сам переклад машинний: «Крапка» замість «Крапля», «Перо» замість «Фезер», «Розділити час на секунди» замість «Флешів за секунду», подекуди турецькі слова в українській колонці. Тут описано, як увімкнути мови, як влаштований словник, що в ньому можна й чого не можна міняти, і лежить наш виправлений словник для двох мов. Зроблено у друкарні Drukva для WellPrint збірки 27102026 (голови i1600, 2 головки), перевірено на живій машині.

## Що лежить у папці

| Файл | Навіщо |
| --- | --- |
| `LocalString.dat` | наш словник для збірки 27102026: усі 541 запис, українська й російська виправлені (93 записи змінено відносно вендорського) |
| `translations_uk_ru.json` | ті самі тексти у вигляді `ID → {uk, ru}` для накладання на іншу збірку |
| `apply-translations.py` | накладає JSON на ваш `LocalString.dat` по ID, нічого не додає й не видаляє, робить бекап |
| `CHANGES.md` | таблиця всіх змін: що було, що стало, у трьох мовах |
| `NoneImportProperty.example.xml` | приклад файлу зі списком мов у меню |
| `patch-configcommon.py` | патч бібліотеки для двох написів, яких у словнику нема (окремий розділ нижче) |

## Крок 1. Увімкнути українську та російську в меню

Список мов, які показує меню, лежить у `AssemblyData\Variable\NoneImportProperty.xml`:

```xml
<vecLanguage>English,Chinese_Simplified,Ukrainian,Russian</vecLanguage>
<next>Ukrainian</next>
```

`vecLanguage` — що буде в меню, `next` — поточна мова. Закрийте WellPrint, допишіть `Ukrainian,Russian`, запустіть, перемкніть мову в меню. Китайську з меню прибрати не можна: WellPrint переписує цей файл при закритті й повертає `Chinese_Simplified` сам.

## Крок 2. Як влаштований словник

Усі підписи інтерфейсу беруться з одного файлу `AssemblyData\Fixed\LocalString.dat`. Це XML (UTF-8 з BOM, рядки CRLF) з 541 записом, у кожному ID і переклади на 9 мов:

```xml
<SubItem>
  <StringResourceId>Move_Left</StringResourceId>
  <StringResourceNode>
    <English>Move Left</English>
    <Chinese_Simplified>向左移动</Chinese_Simplified>
    ...
    <Russian>Двигать влево</Russian>
    <Ukrainian>Рухати вліво</Ukrainian>
    ...
  </StringResourceNode>
</SubItem>
```

Файл читається при старті WellPrint, після правок потрібен перезапуск. Правити можна будь-яким редактором, зберігати як UTF-8 з BOM.

Чотири речі, які треба знати, інакше словник не завантажиться або виглядатиме дивно:

1. **Записи не можна додавати, видаляти чи перейменовувати.** ID це не вільний текст, а зашитий у програму перелік із 541 імені. Невідомий ID дає при старті помилку «Language count mismatch!», і програма лишається з англійською. Міняти можна лише тексти всередині наявних записів.
2. **Порожній переклад не ховає слово.** На його місце програма підставляє англійське, а в деяких режимах китайське слово. Якщо слово зайве, замість порожнього рядка ставте нерозривний пробіл (U+00A0).
3. **Більшість підписів склеюється з кількох однослівних записів.** «Left Lamp Left Print Effective» це п'ять окремих слів: Left, Lamp, Left, Print, Effective. «Setting Export(To File)» це Setting, Export, To, File плюс дужки з коду. Тому одне слово міняє всі екрани, де воно вжите, а порядок слів змінити не можна. Звідси компроміси на кшталт «Друк напрямок» замість «Напрямок друку».
4. **Деяких написів у словнику нема взагалі.** Вони зашиті в бібліотеки: панель «Setting Import/Export» і «Progress», два пункти діалогу білого «Union Set» і «Negation», тексти-інструкції до калібровок (`AssemblyData\Variable\CaliDescription.xml`, лише англійська, китайська та японська). Словником їх не змінити.

## Крок 3. Поставити готовий словник

Якщо у вас збірка 27102026: зробіть копію свого `LocalString.dat`, покладіть замість нього наш і перезапустіть WellPrint.

Якщо збірка інша, файл підміняти не можна, бо перелік ID може відрізнятись. Накладіть переклади по ID:

```
python3 apply-translations.py "C:\WellPrint\AssemblyData\Fixed\LocalString.dat"
```

Скрипт міняє лише тексти в тегах `<Ukrainian>` і `<Russian>` у тих записах, які є у вашому файлі, робить `LocalString.dat.bak` і перевіряє, що XML валідний, а кількість записів не змінилась. Потрібен Python 3, нічого стороннього.

## Що саме ми змінили

Повна таблиця в `CHANGES.md`. Головне, у термінах, якими користуються оператори:

| Було в інтерфейсі | Стало | Чому |
| --- | --- | --- |
| Рухати вниз / вгору / вліво / вправо | Вперед / Назад / Ліворуч / Праворуч | верхня панель руху каретки; англійською теж Forward / Back / Left / Right |
| Плювання, Spit | Флеш, Flash | так кажуть у цеху |
| Перо | Фезер | термін |
| Крапка, Чорнильна крапка | Крапля, Чорнильна крапля | це крапля, не крапка |
| Голівка | Голова | термін |
| Пробіл (Head Space) | Відступ | це відступ, не пробіл |
| Множник чорнила | Кількість шарів | що воно насправді робить |
| Видалити чорнила (Purge) | Протягнути чорнила | прокачка, а не видалення |
| Швидкість: Повільний / Середина / Високий | Повільна / Середня / Висока | рід |
| Розмір краплі: Маленький / Середина / Великий | Мала / Середня / Велика | рід, слово «Середня» спільне зі швидкістю |
| (міліметр) | (мм) | коротше |
| Vazgecmek, Розділити час на секунди, Query = Видалити, порожні російські рядки | виправлено | помилки вендора |
| Меню калібровок | Motor / Step / Bidirection… + Калібрування | щоб назви калібровок збігались з документацією принтера |

Обидві мови правили одночасно, щоб перемикання між ними не міняло термінів.

## Два написи поза словником: патч бібліотеки

У діалозі «Плашковий шар» (генерація білого) пункти «Union Set» і «Negation» беруться не зі словника, а з бібліотеки `ConfigCommon.dll`: там лежать лише англійська й китайська версії, і для будь-якої мови, крім англійської, показується китайська. Бібліотека не підписана, тому ці два рядки й перемикач мови можна поправити прямо в файлі. Скрипт `patch-configcommon.py` робить це для збірки 27102026 і відмовляється працювати, якщо байти не збігаються з очікуваними. Результат: українською «Під каналами» та «Інверсія», іншими мовами «Под каналами» та «Инверсия».

```
copy ConfigCommon.dll ConfigCommon.dll.orig
python3 patch-configcommon.py ConfigCommon.dll.orig ConfigCommon.dll
```

Це модифікація бінарника вендора, робіть на свій ризик і тільки з копією. Після оновлення WellPrint патч треба накладати заново, і він може не підійти до іншої збірки.

Значення пунктів цього діалогу для генерації білого: «Вся область» кладе білий по всьому макету, «Під каналами» там, де є фарба хоч в одному з вибраних каналів, «Перетин каналів» лише там, де вибрані канали перекриваються, «Інверсія» там, де фарби нема.

## Побажання вендору

Усе, що не перекладається, лікується з боку розробника за хвилини: винести в словник написи панелі Import/Export, два пункти діалогу білого і завести окремі записи для склеєних підписів панелі UV-лампи. Тоді цей розділ зведеться до одного файлу словника.
